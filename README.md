# 📡 Servicios Telemáticos

Repositorio creado con el propósito de almacenar y organizar las diferentes prácticas, laboratorios y ejercicios desarrollados durante el curso de **Servicios Telemáticos**.

## 📚 Objetivo

Este repositorio tiene como finalidad:

- Guardar el desarrollo de cada práctica realizada en la asignatura.
- Llevar un control de versiones mediante Git.
- Documentar los avances y soluciones implementadas.
- Servir como material de consulta y referencia para futuros proyectos.

## 📂 Contenido

Cada práctica se encuentra organizada en su respectiva carpeta y contiene los archivos, configuraciones y documentación necesarios para su ejecución.

## 🛠️ Tecnologías

Entre las herramientas y tecnologías utilizadas durante el curso se encuentran:

- Linux
- Git y GitHub
- Bash
- Redes y Servicios Telemáticos
- Virtualización (Vagrant y VirtualBox)
- Protocolos y servicios de red
